Deploy checklist

  • Run the Python backend on a Python host with persistent storage.
  • Set Discord OAuth redirect URI to your backend's /auth/callback.
  • Keep this page and the bot pointed at the same data.json and premium.json.
  • Cloudflare Pages can host the HTML, but it cannot run this Flask app directly as a Python service.
